# Documentation changelog

## 2026-11-03 — Published from the website

Documentation now moves one way from the website on each deploy, under `content/`
instead of `pages/`. This repo no longer builds its own docs site. It still holds
public issues, discussions and the starters.

## 2026-10-21 — Documentation baseline 5.2.0

Corrected onboarding exports and editable state types, React requirements and
component imports. Aligned starters and lockfiles with npm 5.2.0. Added complete
Vite/Next.js guides and a Next.js starter, agent-oriented Markdown resources,
licensing and troubleshooting guidance, and public verification workflows.

These are documentation/starter changes, not a new npm package release.
See `content/releases.mdx` for compatibility and upgrade instructions.
