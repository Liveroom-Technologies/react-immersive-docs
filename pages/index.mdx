# `@liveroom-tech/react-immersive`

A React 3D model viewer for interactive 3D assets, mesh selection, object bindings, built-in UI panels, and a full suite of hooks for camera, animations, visibility, and more.

## Features

- **GLB/GLTF, OBJ/MTL, FBX, and USDZ rendering** via React Three Fiber
- **Mesh selection** by object name with built-in side panels
- **Object bindings**, drive transforms, color, texture, visibility, and actions from a plain data record
- **Object move & rotate controls**, geometry-centered handles with World or Local axis alignment
- **Shadows & post-processing**, soft shadows (auto-tuned for interiors), SSAO, bloom, and ACES tone mapping, toggleable via the `shadows` prop
- **SimpleModelViewer**, a lightweight model inspection viewer with no `objectBindings` required
- **BindingBuilder**, browser-based design-time tool for generating bindings and positioning model objects
- **Hooks API**:
  - [`useViewerCamera`](/hooks/use-viewer-camera)
  - [`useViewerConnection`](/hooks/use-viewer-connection)
  - [`useViewerAnimations`](/hooks/use-viewer-animations)
  - [`useViewerEffects`](/hooks/use-viewer-effects)
  - [`useViewerSelection`](/hooks/use-viewer-selection)
  - [`useViewerHover`](/hooks/use-viewer-hover)
  - [`useViewerModel`](/hooks/use-viewer-model)
  - [`useViewerActions`](/hooks/use-viewer-actions)
  - [`useObjectBinding`](/hooks/use-object-binding)
  - [`useObjectBindings`](/hooks/use-object-bindings)
  - [`useSceneConfig`](/hooks/use-scene-config)
  - [`useShareableViewerState`](/hooks/use-shareable-viewer-state)

## Minimal Example

```tsx
import objectBindings from "./objectBindings.json";
import {
  ModelViewer,
  type ObjectBinding,
} from "@liveroom-tech/react-immersive";

const initialBindings = objectBindings as Record<string, ObjectBinding>;

export default function App() {
  return (
    <div style={{ height: "100vh" }}>
      <ModelViewer
        modelUrl="/model.glb"
        licenseKey="your-license-key"
        objectBindings={initialBindings}
      />
    </div>
  );
}
```

`objectBindings` is required. You can author it by hand, or generate starter
bindings in [`BindingBuilder`](/reference/binding-builder) and export them as
`objectBindings.json` or a TypeScript file to import into your app.

<Callout type="info">
  UI styles ship as an explicit static CSS import; the package does not inject
  runtime style tags. Tailwind is **not** required in the consuming app.
</Callout>

## Quick Inspection With `SimpleModelViewer`

If you don't need `objectBindings`-driven styling and actions, [`SimpleModelViewer`](/reference/simple-model-viewer) gives you a lightweight viewer for inspecting GLB, GLTF, OBJ, FBX, or USDZ assets. It can also run in an upload-first mode for ad-hoc local model inspection:

```tsx
import { SimpleModelViewer } from "@liveroom-tech/react-immersive";

export default function App() {
  return (
    <div style={{ height: "100vh" }}>
      <SimpleModelViewer modelUrl="/model.glb" />
    </div>
  );
}
```

## Exports

```ts
import {
  BindingBuilder,
  material,
  ModelViewer,
  patchBindings,
  patchSceneConfig,
  SimpleModelViewer,
  useObjectBinding,
  useObjectBindings,
  useSceneConfig,
  useViewerActions,
  useViewerAnimations,
  useViewerEffects,
  useViewerCamera,
  useViewerConnection,
  useViewerHover,
  useViewerModel,
  useViewerSelection,
} from "@liveroom-tech/react-immersive";
```

Pure data helpers such as `defineObjectBindings`, `patchBindings`,
`patchSceneConfig`, and `selectBindings` are also available from the
server-safe `@liveroom-tech/react-immersive/utils` entry point. The main entry
continues to export them for backwards compatibility.
