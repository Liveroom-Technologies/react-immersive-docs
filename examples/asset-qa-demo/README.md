# Asset QA

Inspect a sample model or a local file, focus meshes from the diagnostics report, and download the report.

## Run

Create a key in the [React Immersive console](https://react-immersive.liveroom.dev/console).

```bash
npm ci
VITE_LICENSE_KEY=your-license-key npm run dev
```

In CodeSandbox, set `VITE_LICENSE_KEY` in Environment Variables and restart the
preview. Use a production-enabled key registered for the preview’s domain.
